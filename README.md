# 선형·비선형 회귀분석 프로그램

이 프로그램은 CSV 또는 Excel 형식의 실험 데이터를 입력받아 **선형회귀와 다양한 비선형 회귀모델을 적용하고, 회귀곡선·잔차·성능지표를 비교할 수 있도록 만든 웹 기반 회귀분석 프로그램**입니다.

Python과 Streamlit을 이용하여 제작하였으며, 웹브라우저에서 데이터를 업로드한 뒤 독립변수(X)와 종속변수(Y)를 선택하고 원하는 회귀모델을 실행할 수 있습니다. 분석 결과는 그래프와 표로 확인할 수 있으며, 결과를 Excel 파일과 HTML 그래프로 저장할 수 있습니다.

---

## 1. 프로그램 개발 목적

실험 및 공학 데이터는 항상 직선 형태의 관계를 가지지 않습니다. 따라서 단순한 선형회귀만으로는 데이터의 경향을 충분히 설명하기 어려운 경우가 있습니다.

이 프로그램은 하나의 데이터에 여러 회귀모델을 적용하여 다음 내용을 한 번에 확인할 수 있도록 제작하였습니다.

- 선형회귀 결과 확인
- 비선형 회귀곡선 확인
- 여러 회귀모델의 적합도 비교
- 잔차를 이용한 오차 분석
- 이상치 후보 확인
- 새로운 X 값에 대한 Y 값 예측
- 분석 결과 저장

## 4. 필요한 Python 라이브러리

프로그램 실행에 필요한 외부 라이브러리는 `requirements.txt` 파일에 정리되어 있습니다.

```txt
streamlit>=1.42
numpy>=1.24
pandas>=2.0
scipy>=1.10
plotly>=5.20
openpyxl>=3.1
xlrd>=2.0
```

각 라이브러리의 역할은 다음과 같습니다.

| 라이브러리 | 역할 |
|---|---|
| `streamlit` | 웹 화면 구성, 파일 업로드, 버튼, 표, 다운로드 기능 |
| `numpy` | 수치 계산, 배열 연산, 다항 회귀 계산 |
| `pandas` | CSV/Excel 데이터 읽기, 데이터 전처리, 결과 표 생성 |
| `scipy` | 비선형 회귀 최적화, 통계 계산, 신뢰구간 계산 |
| `plotly` | 회귀 그래프와 잔차 그래프를 웹에서 표시 |
| `openpyxl` | `.xlsx` Excel 파일 읽기 및 쓰기 |
| `xlrd` | `.xls` 형식의 구형 Excel 파일 읽기 |

다음 모듈도 코드에서 사용하지만 Python 기본 라이브러리이므로 별도로 설치하지 않아도 됩니다.

- `io`
- `math`
- `dataclasses`
- `typing`

## 10. 회귀모델 설명

### 10.1 선형 회귀

```text
y = ax + b
```

X와 Y 사이의 관계를 직선으로 근사합니다.

프로그램에서는 관측값과 회귀선 사이의 오차 제곱합이 최소가 되도록 계수를 계산합니다.

### 10.2 2차 다항 회귀

```text
y = ax² + bx + c
```

데이터가 직선보다 곡선 형태에 가까울 때 사용할 수 있습니다.

### 10.3 3차 다항 회귀

```text
y = ax³ + bx² + cx + d
```

2차 회귀보다 더 복잡한 곡률 변화를 표현할 수 있습니다.

### 10.4 지수 회귀

```text
y = a·exp(bx) + c
```

X 증가에 따라 Y가 빠르게 증가하거나 감소하는 형태의 데이터에 사용할 수 있습니다.

### 10.5 로그 회귀

```text
y = a·ln(x) + b
```

X가 증가할수록 Y의 변화량이 점차 감소하는 형태의 데이터에 사용할 수 있습니다.

주의: 로그 함수의 특성상 X 값은 0보다 커야 합니다.

### 10.6 거듭제곱 회귀

```text
y = a·xᵇ
```

공학 데이터의 비선형 관계나 크기 변화에 따른 스케일 관계를 표현할 때 사용할 수 있습니다.

주의: 현재 프로그램에서는 X가 0보다 큰 데이터에서 사용합니다.

### 10.7 4-모수 로지스틱 회귀

```text
y = lower + (upper - lower) /
    (1 + exp(-slope·(x - midpoint)))
```

S자 형태의 데이터를 표현하는 데 사용할 수 있습니다.

## 11. 회귀 계산 방법

### 선형, 2차, 3차 다항 회귀

NumPy의 다항식 최소제곱 적합을 사용합니다.

관측값과 모델 예측값의 차이인 잔차의 제곱합이 최소가 되도록 회귀계수를 계산합니다.

### 지수, 로그, 거듭제곱, 4-모수 로지스틱 회귀

SciPy의 `curve_fit` 기능을 사용하여 회귀모델의 파라미터를 반복적으로 조정하는 비선형 최소제곱 최적화를 수행합니다.

## 12. 평가 지표 설명

### 결정계수 R²

모델이 Y 데이터의 변동을 어느 정도 설명하는지를 나타내는 지표입니다.

일반적으로 1에 가까울수록 데이터에 잘 맞습니다.

단, 결정계수가 높다고 해서 항상 가장 좋은 모델이라는 의미는 아닙니다. 모델이 지나치게 복잡하면 과적합이 발생할 수 있습니다.

### 수정 결정계수

모델의 파라미터 수를 고려해 결정계수를 보정한 값입니다.

### 평균제곱근오차

```text
RMSE = sqrt(mean((Y - Ŷ)²))
```

값이 작을수록 관측값과 예측값의 차이가 작습니다.

### 평균절대오차

```text
MAE = mean(|Y - Ŷ|)
```

값이 작을수록 모델의 평균적인 예측 오차가 작습니다.

### 잔차제곱합

```text
SSE = Σ(Y - Ŷ)²
```

값이 작을수록 관측 데이터에 잘 적합된 것입니다.

### 아카이케 정보기준

모델의 적합도와 복잡도를 함께 고려하는 지표입니다.

일반적으로 값이 낮을수록 더 적합한 모델로 판단합니다.

### 수정 아카이케 정보기준

표본 수가 많지 않을 때 아카이케 정보기준을 보정한 값입니다.

이 프로그램에서는 가능한 경우 **수정 아카이케 정보기준 값이 가장 낮은 모델을 최적 모델로 표시**합니다.

### 베이지안 정보기준

아카이케 정보기준과 비슷하지만 모델 복잡도에 더 큰 불이익을 주는 지표입니다.

## 13. 잔차 분석

잔차는 다음과 같이 정의합니다.

```text
잔차 = 관측값 - 예측값
```

잔차가 0에 가까우면 해당 데이터에서 모델의 예측값과 실제 관측값이 비슷하다는 뜻입니다.

잔차 그래프에서는 예측 Y 값을 X축에, 잔차를 Y축에 표시합니다.

---

## 14. 이상치 후보 판정

프로그램은 표준화 잔차를 이용하여 이상치 후보를 표시합니다.

현재 기준은 다음과 같습니다.

```text
|표준화 잔차| ≥ 2
```

표준화 잔차의 절댓값이 2 이상인 데이터는 이상치 후보로 표시됩니다.

이상치 후보 표시는 해당 데이터를 자동으로 삭제한다는 의미가 아닙니다.

실험 오류, 센서 문제, 실제 물리 현상 등 여러 원인이 있을 수 있으므로 사용자가 원본 데이터를 확인한 뒤 판단해야 합니다.

## 18. 예제 데이터

`sample_data.csv`는 UCI Machine Learning Repository의 **Yacht Hydrodynamics** 공개 데이터셋에서 가져온 선박 유체역학 실험 데이터 일부입니다.

이 데이터는 Delft Ship Hydromechanics Laboratory에서 수행된 요트 선형 관련 실험 데이터이며, 선형 형상계수와 프루드수 변화에 따른 잉여저항을 포함합니다.

### 예제 데이터 열 설명

| 열 이름 | 의미 |
|---|---|
| `LCB_Position` | 부심의 종방향 위치 |
| `Prismatic_Coefficient` | 주형계수 |
| `Length_Displacement_Ratio` | 길이-배수량 비 |
| `Beam_Draught_Ratio` | 폭-흘수 비 |
| `Length_Beam_Ratio` | 길이-폭 비 |
| `Froude_Number` | 프루드수 |
| `Residuary_Resistance_per_Displacement` | 배수량 단위중량당 잉여저항 |

### 예제 데이터 권장 설정

```text
X 열: Froude_Number
Y 열: Residuary_Resistance_per_Displacement
```

이 조합을 사용하면 프루드수 증가에 따른 잉여저항 변화를 분석할 수 있어 선형회귀와 비선형회귀를 비교하기에 적합합니다.

### 예제 데이터 출처

Gerritsma, J., Onnink, R., & Versluis, A. (1981). Yacht Hydrodynamics. UCI Machine Learning Repository.

자료 식별번호: 10.24432/C5XG7R

## 20. 오류 해결 방법

### requirements.txt 파일을 찾을 수 없는 경우

```text
ERROR: Could not open requirements file:
[Errno 2] No such file or directory: 'requirements.txt'
```

현재 명령 프롬프트 위치에 `requirements.txt` 파일이 없는 경우 발생합니다.

프로그램 파일이 있는 폴더로 이동한 뒤 다시 실행합니다.

```bash
cd C:\Users\USER\Downloads\Regression-Analysis-Tool
python -m pip install -r requirements.txt
```

### streamlit 명령을 찾을 수 없는 경우

```bash
python -m streamlit run Regression_Analyzer_Web.py
```

### 라이브러리 버전 충돌이 발생하는 경우

새 가상환경 생성을 권장합니다.

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

### 로그 회귀 또는 거듭제곱 회귀가 실패하는 경우

X 값에 0 또는 음수가 포함되어 있는지 확인합니다.

### 특정 회귀모델만 계산에 실패하는 경우

모든 데이터가 모든 회귀모델에 적합한 것은 아닙니다.

특정 모델이 계산에 실패하더라도 다른 모델의 분석은 계속 진행됩니다.

## 21. 프로그램 요약

본 프로그램은 실험 데이터를 입력받아 여러 선형·비선형 회귀모델을 적용하고, 각 모델의 회귀곡선과 통계지표를 비교할 수 있도록 제작한 웹 기반 데이터 분석 프로그램입니다.

단순히 회귀곡선을 그리는 기능뿐 아니라 잔차 분석, 이상치 후보 검출, 95% 신뢰구간, 모델 선택, 예측 및 결과 저장 기능을 포함하여 실험 데이터 분석 과정을 하나의 프로그램에서 수행할 수 있도록 구성하였습니다.
